# ウミガメ群体(デスクトップの人工生命ペット)

画面の表示はすべて英語(Ver 1.1.0〜)。Ver 2.0.0 で生態系・砂浜での産卵・性格・情報表示を追加。Ver 3.0.0 で波・クラゲの餌やり・ついて回るステータス・なでる・サメ・息継ぎを追加(泡とゴカイは削除)。Ver 3.1.0 で昼夜(パソコンの時計に合わせる)を追加。

`umigame_pet.py` 1ファイル。Python 標準ライブラリ(tkinter)だけで動く。`pip install` 不要。
起動: `umigame_pet.py` をダブルクリック、または `python umigame_pet.py`。

## 遊び方
| 操作 | 反応 |
|---|---|
| カメをクリック | ステータス(番号・性別・系統・世代・年齢/寿命・健康・機嫌・食性・性格・親・なでた回数・今していること)がカメについて回る。もう一度クリックで消える |
| カメをダブルクリック | ひっくり返ってジタバタ → 機嫌が良ければ回って喜ぶ、悪ければ怒って逃げる |
| カメの上でカーソルを動かす | なでる。カーソル好きは喜ぶ(♥/♪)、カーソル嫌いはうっとうしがる(💢)。寝ているカメはそのまま寝ていることも |
| マウスを近づける | 性格しだいで寄ってくる・嫌がって逃げる・気にしない |
| マウスを素早く動かす | びっくり(!)して逃げる(無頓着な個体は平気) |
| 卵・水草・クラゲ・サメに重ねる | 説明を表示 |
| 水をクリック | クラゲを落とす(雑食のカメが食べる) |
| Shift+クリック | 水草を植える |
| 右クリック | 最前面に固定 / 解除 |
| L キー | 各カメの横に系統の文字を表示 / 消す |
| ウインドウを閉じる | 群体を保存 |

## しくみ
- 画面: 上から見た南国の海(ターコイズのグラデーション)と砂浜。沖から白い波が寄せてくる。
- 遺伝子: 色(2つ)・甲羅の模様(28bit)・速さ・寿命(4〜12時間)・大きさ・食性・産卵数と、性格の遺伝子
  (活発さ・食欲・カーソルの好き嫌い・群れたがり・無頓着さ・気まま・気の短さ)。
  交尾で両親の遺伝子を交叉(スクランブル)+突然変異するので、甲羅の色と模様で系統が見分けられる。系統(Lineage A, B…)は母系。
- 性格のラベル: Sleepyhead(寝てばかり)/ Energetic(活発)/ Big eater(よく食べる)/ Light eater(少食)/
  Cursor lover(カーソルに集まる)/ Cursor shy(カーソルを嫌う)/ Schooler(群れたがる)/ Loner(一人が好き)/
  Middle-of-the-road(中庸)/ Carefree(何も気にしない)/ Free spirit(気まま)/ Short-tempered / Easygoing。
- 食性: 草食(Herbivore)は水草だけを食べ、水草からの栄養が多い。雑食(Omnivore)は水草とクラゲを食べる。
- 生態系: 水草は増えて隣へ広がり、食べられると減る(根は残って再生)。死骸は分解されて近くの水草の栄養になる。
  クラゲは沖から流れてくる。カメが増えすぎると水草が減って餓死が増える。右上のグラフで増減が見える。
- サメ: まれ(20〜45分に1回)に沖に現れ、大きさ x3 以上のカメを狙う。カメはサメに気づくと浅瀬へ逃げる(サメは浅瀬に来ない)。
- 息継ぎ: カメはときどき海面に浮上して息継ぎをする(波紋が広がる)。活発な個体ほど間隔が短い。
- イベント(左下に表示): 交尾 → メスが砂浜に上がって産卵 → 3分でふ化 → 子ガメは海へ。
  合体(近縁どうしが1体の大きな個体に)・分裂(合体した個体が満腹だと2体に)・死(老衰/餓死/サメ)・サメの出現。
- 昼と夜(パソコンの時計に合わせる): Night / Dawn twilight(薄明)/ Sunrise / Daytime / Sunset(夕焼け)/ Dusk(薄暮)。
  日の出・日の入りは日本(東京付近)の季節変化を簡単な式で近似(夏至ごろ 4:24 / 19:00、冬至ごろ 6:48 / 16:30)。
  海・砂浜・生き物の色みが時間帯で変わり、水面に太陽・月のきらめきが映る。時間帯が変わると画面とイベント欄で知らせる。
  - 夜: ほとんどのカメが眠る(活発な個体は夜ふかし)。動きもゆっくり。寝ていても息継ぎには浮上する。
  - 朝(日の出): 目を覚まして喜ぶ。お腹がすきやすい。
  - 夕焼け・薄暮: 仲間と寄り集まる。
  - 産卵: 卵を持ったメスは暗くなってから(夕焼け〜夜〜薄明)砂浜に上がる(ウミガメの習性)。
  - サメ: 夕方〜夜に現れやすい。
  - 留守中の計算も、閉じた時刻からの昼夜を再現する。
- 絶滅すると、記憶していた遺伝子から新しい系統の卵が砂浜に流れ着く。
- 軽さ: 10fps、スプライトは個体ごとに作って使い回す。最小化中は描画せず1秒ごとに計算のみ。カメ+卵は最大40。

## 保存(Google ドライブ)
閉じたとき(と5分ごと)に `colony.json` を保存。次回起動時、閉じていた実時間ぶん(最大7日)群体の時間を進め、
「While you were away: ◯ passed / Born ◯ Died ◯ Eggs laid ◯」と表示する(Ver 1 の保存データも読める)。
保存先は「パソコン版 Google ドライブ」の同期フォルダ(`G:\マイドライブ\UmigamePet\` など)を自動で探す。
見つからなければ `ホーム\UmigamePet\` に保存し、タイトルに「(saved locally)」と出る。
環境変数 `UMIGAME_SAVE_DIR` で保存先を指定できる。
