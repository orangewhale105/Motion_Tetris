# ウミガメ群体(デスクトップの人工生命ペット)

`umigame_pet.py` 1ファイル。Python 標準ライブラリ(tkinter)だけで動く。`pip install` 不要。
起動: `umigame_pet.py` をダブルクリック、または `python umigame_pet.py`。

## 遊び方
| 操作 | 反応 |
|---|---|
| マウスを近づける | 社交的な個体は寄ってきて ♥/♪、気の短い個体はうっとうしがって 💢 で逃げる |
| マウスを素早く動かす | びっくり(!)して逃げる |
| カメをクリック | ひっくり返ってジタバタ → 機嫌が良ければ回って喜ぶ(♪)、悪ければ怒って逃げる |
| 寝ているカメをクリック | 起こされて怒る/きょとん(?) |
| 水をクリック | えさ(クラゲ)を落とす |
| 右クリック | 最前面に固定 / 解除 |
| ウインドウを閉じる | 群体を保存 |

## しくみ
- 遺伝子: 色・模様(甲羅のドット 28bit)・速さ・寿命(4〜12時間)・代謝・社交性・気性・眠りやすさ・大きさ。
- 大人(20分)になり満腹だと相手を探して交尾 → 卵(3分でふ化)。子の遺伝子は両親の交叉+突然変異。
- えさを取れない個体は餓死、寿命が来ると仰向けになって浮かんで消える(自然選択)。
- 近縁(遺伝距離が近い)どうしが触れると、ときどき合体して1体の大きな個体になる(空腹時に起きやすい)。
- 個体+卵は最大24。絶滅すると、記憶していた遺伝子から卵が流れ着く。
- 軽さ: 10fps、スプライトは個体ごとに1回だけ作って使い回す。最小化中は描画せず1秒ごとに計算のみ。

## 保存(Google ドライブ)
閉じたとき(と5分ごと)に `colony.json` を保存。次回起動時、閉じていた実時間ぶん(最大7日)群体の時間を進め、
「留守の間に◯経過 誕生◯ 死亡◯」と表示する。
保存先は「パソコン版 Google ドライブ」の同期フォルダ(`G:\マイドライブ\UmigamePet\` など)を自動で探す。
見つからなければ `ホーム\UmigamePet\` に保存し、タイトルに「ローカル保存」と出る。
環境変数 `UMIGAME_SAVE_DIR` で保存先を指定できる。
