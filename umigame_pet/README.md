# Sea Turtle Colony(ウミガメ群体)

デスクトップで動く人工生命のペット。`umigame_pet.py` 1ファイル、Python 標準ライブラリ(tkinter)だけで動く。
起動: `umigame_pet.py` をダブルクリック、または `python umigame_pet.py`。画面の表示は英語。

深海版は [../whale_fall/](../whale_fall/)(Whale Fall)。

## 操作
| 操作 | 反応 |
|---|---|
| カメをクリック | ステータス(性別・系統・世代・年齢/寿命・健康・機嫌・食性・見た目・性格・パートナー/友達・親・今していること)がカメについて回る。もう一度で消える |
| カメを長押し(0.7秒) | 識別個体にして名前をつける。名前が頭の下に出て、一生(食べた量・子ども・子孫・サーフィン・病気など)が記録される。亡くなると、どんな亀生だったかと死因のメッセージが出て、生きている子孫を選んで追いかけることもできる |
| カメをダブルクリック | ひっくり返ってジタバタ → 機嫌しだいで喜ぶ/怒る |
| カメの上でカーソルを動かす | なでる(カーソル好きは喜ぶ、嫌いな子は嫌がる) |
| マウスを近づける・素早く動かす | 寄ってくる / 逃げる / 気にしない / びっくり |
| 卵・水草・サンゴ・岩・熱帯魚・クラゲ・訪問者に重ねる | 説明 |
| 水を左クリック / 右クリック(Shift+クリックも可) | クラゲを足す / 海藻を植える |
| T / L / R | 最前面 / 系統の文字 / 友達(黄)・パートナー(ピンク)の線 |

## しくみ(Ver 4.0)
- 時間(Ver 7.0〜): カメの時間は実時間の36倍。実時間の40分がカメの1日(0:00・0:40・1:20 … がカメの0:00、その20分後が正午)。画面左上に「Day 3  12:01 Daytime」のように出る。
  カメの時間で進むもの: 年齢・寿命(20〜36時間)・大人になるまで(5時間)・おなかのすき具合・眠気・卵(1.5時間+夜を待つ)・水草の育ち方と寿命・朝昼夕夜の色と1日の行動。カメの1日でおよそ1世代。
  実時間のままのもの: 泳ぐ速さ・息継ぎ・アニメーション・波・訪問者の来る間隔(サメ約30分など)。
  夏の日のイメージ(日の出 4:36、日の入り 18:54。カメの時刻)。留守中はカメの時間で最大30日(実時間30時間)まで進める。
- カメの1日(ウミガメの生態に合わせた): 朝(5〜10時)と夕方(15〜19時)によく食べる。昼(11〜14時)はサンゴでくつろぎ、熱帯魚にクリーニングしてもらう。夜は岩場やサンゴのそばで眠る(寝ていても息継ぎに浮上)。産卵は夜に砂浜で。子ガメも夜にふ化して海へ。
- 見た目: パステル(水色・ピンク・ミント・レモン・ラベンダー・ピーチ)。模様は地の色と同じ系統(Ver 7.0〜、補色は使わない)。まれ(約3%)に真珠色・金色。甲羅の模様 8 種類(無地・水玉・しま・亀甲・リング・まだら・市松・ハート[とてもまれ])。交叉で色と模様が受け継がれ、系統が分かる。
- 息継ぎ: 首をのばして頭を水面に出し(白い輪)、波紋が広がる。
- 波: 沖から寄せる波。15〜40分に1回の大波で小さいカメがひっくり返る。大波が来ると、遊び好きのカメは沖へ泳いで波をつかまえ、岸に向かってサーフィンする。たいていは途中でワイプアウトしてくるくる回り(岸まで乗り切れるのは4匹に1匹くらい)、照れたりしょんぼりしたりする。
- 関係: 近くで過ごすと友達、交尾した相手はパートナー(次もその相手を選びやすい)。仲良しは一緒に泳ぎ、会うと喜ぶ(♪・照れ・♥)。仲間が死ぬと泣く。群れ好きは一人だとさみしがり、一人好きは混むとうっとうしがる。
- 食べるようす(Ver 5.0): クラゲと同じく、水草も株を丸ごと食べると消える(葉が舞い、緑の輪)。カメはそのあと口をもぐもぐ動かしてから離れる。食べるのは半分以上育った株だけで、小さい株は育って広がり、藻場が再生する。
- クリーニング(Ver 4.5): 熱帯魚がカメの体の上に集まり、甲羅やひれの一点へ行ってはつついて(キラッと光る)、また別の場所へ移る。カメはじっとして、ひれをゆっくり動かす。
- 夜(Ver 5.1): 月光で海が銀色にきらめき、泳ぐカメのあとに夜光虫が青く光る。夜行性の生き物が出てくる:
  ヤドカリ(何匹も)・ヤシガニ・スナガニ(走っては止まり、浜を這う子ガメをねらう)、海ではタコ(岩場から岩場へ、色を変える)とクシクラゲ(虹色に光る)。
- 朝焼け・夕焼け(Ver 5.1): 海も浜も真っ赤に染まり、太陽の光の道が赤く輝く(真っ赤な時間を長めにした)。
- 死因(Ver 5.1): 餓死・病死(混み合いや空腹・年をとるとかかりやすい。クリーニングで治ることも)・老衰・食べられた(サメは「Tiger shark #3」のように個体名で、子ガメはスナガニにも)。
- 運のよい個体(約1/10)は実時間で1週間ほど生きる。
- 外から来るカメ(Ver 5.1): 実時間20〜40分に1回、遠くの海から別の系統のカメがやって来る。オスとメスの数が偏っているときは少ない方の性別で、オスだけ・メスだけになったときはすぐに来る。
- 海藻(Ver 4.4): 群生した藻場は、株が食べられると小さくなり、食べられなければまた育つ。茂った株はすぐ隣に広がり、
  株には寿命(4〜8時間)もあるので、藻場は形を変えながら少しずつ移動する。根元まで何度も食べられた株は枯れ、
  株がなくなると藻場は消える。ときどき海のどこかに単独の芽が出て、運よく食べられなければ育って新しい藻場になる。
  カメが増えすぎると海藻がなくなり、餓死することもある。死骸は水草の栄養に。
- 訪問者(Ver 4.4、左ほどまれ): サメ(約30分に1回。大きなカメを狙うが、たいていは間一髪で逃げる)、イルカ(約20分に1回、昼。ジャンプする)、
  マンタ(約15分に1回、昼〜夕。宙返りする)、ヤシガニ(夜の砂浜、約1分に1回)、ヤドカリ(約1分に1回。貝殻を引っ越す)。
  イルカとマンタにはカメが集まって一緒に遊ぶ。どの生き物も頭の向きに泳ぐ・歩く。
- 合体(近縁どうし)・分裂(合体した個体が満腹のとき)。
- 大きさ(Ver 4.1): 子ガメ x2、若いカメ x2〜3、大人 x3〜4(合体で最大 x6)。サメが狙うのは x4 以上。
- 音(Ver 4.2): 寄せては返す波の音(12秒のループ)と効果音(しぶき・もぐもぐ・♪・♥・息継ぎ・びっくり・ひっくり返る・怒る・ふ化・産卵・合体・サーフィン・イルカ・時間帯の鐘・大波・サメ・噛みつき・死)。
  音はプログラムの中で合成し、最初に一時フォルダへ作る(音のファイルは不要)。うるさくならないよう、同じ音の連続と1秒に5つ以上は鳴らさない。
  砂浜の右下のボタン(または W / F キー)で、波の音・効果音をそれぞれ ON/OFF できる。
  音量(Ver 4.3): それぞれのボタンの左右の「−」「+」、またはボタンの上でマウスホイールで 0〜100%(10%きざみ)。最初は波 60%・効果音 70%。設定は保存される。
  再生: pygame が入っていれば pygame、無ければ Windows 標準の winmm、macOS は afplay、Linux は paplay/aplay。
- 軽さ: 10fps、スプライトは個体ごとに作って使い回す。最小化中は描画しない。カメ+卵は最大40。

## Ver 6.0 の追加
- 保存先: 初回起動時にフォルダを選ぶ画面が出る(選んだ場所は `ホーム/.umigame_pet_config.json` に記録。O キーで変更)。
- 時間: 画面左上の Day と時刻はカメの時間(実時間1時間 = 1日)。寿命は平均4〜5日、運のよい個体(約1/10)は15〜30日。ほかに食べられたり病気で死ぬことも。大人になるのは約20時間、卵は6時間+夜を待ってふ化。
- 変化が感じられるように: カメが増える → 食べられる海藻が減る → 餓死が増える → 数が減る → 海藻が戻る、をイベント欄で知らせる(「The colony is growing!」「The seaweed is running out」「Hard times...」「The seaweed meadows are recovering」)。グラフは2日分で、食べられる大きさの海藻の量(Food)を表示。
- 動くとおなかが減る(速く泳ぐほど)。
- 感情が伝わる動き: 起きた直後は寝ぼけてよろよろ、元気な個体はときどきダッシュ、気ままな個体はくねくね泳いで立ち止まりきょろきょろ。弱った個体(空腹・病気・高齢)は色が薄く、ゆっくりで、ときどき止まる。
- 性格の遺伝子を追加(イベントの起こりやすさ): 波乗り好き(Surf lover)・観察好き(Naturalist: ほかの生き物をじっと見る)・浅瀬好き/沖合好き・メスを追いかけ回す(Flirt)・おっちょこちょい(Clumsy: 勝手にひっくり返る・岩に頭をぶつける・何をしに来たか忘れる・ワイプアウトしやすい)。
- クリックで出るステータスに、性格のユーモラスな説明と、出身(Native / Newcomer: Wanderers II など / その家系)を表示。外から来るカメは、来るたびに別の群れ(Wanderers I, II, ...)。1〜3匹で来る。
- 交尾: 寄りそってくるくる回り、ハートがあふれ、恋の和音が鳴る。
- 産卵: 穴を掘る → 涙を流しながら産む → 砂をかける。ふ化: 卵がゆれて割れ、子ガメが月明かりの中を海へ。
- 海鳥(グンカンドリ): ふ化すると半分くらいの確率でやって来て、浜を這う子ガメを急降下でねらう。
- 訪問者は時間帯で出やすさが変わる(イルカは昼、マンタ・タコは夕方〜夜、サメは夕方〜夜に多い、など)。夜の海にウツボ(岩から顔を出す)とイカの群れを追加。
- 岩場を5か所に。サンゴは育つ向きに広がり、反対側が崩れたり白化したりして、少しずつ移動する。
- 水草を食べたときの緑の輪をなくした。

## Ver 7.0 の変更
- 時間: 実時間の40分 = カメの1日。食べる・海藻が育つ速さは実時間あたり Ver 6 と同じ。
- 色: 毒々しい補色の模様をなくした(地の色に近い色相だけ)。まれな濃い色は真珠色(pearl white)か金色(golden)に。色は遺伝子から描くときに決まるので、保存済みのカメも新しい色になる。
- 岩場: 開始時に 大(岩8個)・中(5個)・小(3個)と、サメの来る沖合に小(3個)の4か所をランダムに置く。
- サンゴ: 開始時は4つ。大きくなったり小さくなったり移動したりし、新しいサンゴ礁ができたり、小さくなったサンゴ礁が消えたりする(最大7つ)。熱帯魚の数はサンゴの大きさに比例して、少しずつ増減する。サンゴ・熱帯魚・クラゲは遺伝子を持たない(遺伝子はカメだけ)。
- 海藻・サンゴの下の楕円をなくした(陸地まではみ出していたため)。
- クラゲ: 海の中をただよい、分裂してふえ、自然に死ぬ(海が養える数は約14)。外からは来ないので、カメが食べ過ぎると絶滅する → 水を左クリックで足す。
- 餌探し: 夜でも小食の個体でも、おなかが半分を切ったら餌を探す。おなかがすくと少し小さめの株も食べる。腹ぺこでは眠らず、寝ていても目がさめて食べに行く。弱っていても餌へは必死に向かう。産卵前に腹ぺこならまず食べる。
- 産卵: 本物のウミガメに合わせ、夜20時〜翌3時に上陸し、約1時間半(カメの時間)かけて穴を掘る → 産む → 砂をかける。
- 増えすぎ: 1匹あたりの海藻が少ないと恋をしない。さらに少ないと、何匹かが「他の海域へ旅立つ」(The seaweed is scarce... set off for a faraway sea, never to return)。旅立ったカメは二度と戻らない。子ガメも多くはそのまま外洋へ(海藻が少ないほど多い)。
- 絶滅の危機: 平均21日に1度(最低6日あく)、嵐・赤潮・伝染病・海藻の不作のどれかが起こり、数が大きく減る。9回に1回ほどは全滅(およそ半年に1度の絶滅)。以前の「絶滅したら卵が流れ着く」はやめた。
- 外来ガメ: 来やすさは今いる数に反比例(カメの1日あたり 1/(数+1) 回)。絶滅したら1日ほどで1匹、3日ほどでペアになれるくらい。少ない方の性で来る。年齢は大人になるかならないかの若さ、世代は Gen 1 から。
- 識別個体が亡くなったとき(または旅立ったとき)、生きている子孫の中から遺伝子・見た目がいちばん近い3匹を候補に出し、識別するか([No, thanks] で しない)を選べる。
- 最前面の切り替えは T キーに(右クリックは海藻)。

## Ver 7.1 の変更
- 効果音: サメが現れると、低い半音がだんだん速くなる不気味な音。サメが襲いかかる・かみつくと不協和な強打(attack)。イルカはキュイキュイと口笛・クリックのはずむ声、マンタはマリンバのような楽しげなアルペジオ。大波は遠くから近づく長いうなり、カメがひっくり返されると砕ける音(crash)。
- 交尾をまれに(本物のウミガメに合わせて): メスは一度交尾すると約2.5日、オスは約1.2日は交尾しない。メスは精子をたくわえ、交尾なしでもう1〜2回、約20時間おきに同じ父親の卵を産む。相手を探し始めるのも、のんびり(実時間で平均1分半に1回の機会)。メスを追いかけ回すのも少なく。
- 絶滅の危機で減る割合を 35〜70% に(全滅は今までどおり 9 回に 1 回ほど)。

## Ver 7.2 の変更(のんびり気ままが基本)
- 交尾: 朝(6〜10時)だけ、1日に1〜2ペアまで。寄りそってハートが1つ出るだけ(くるくる回る・ハートがあふれる演出はやめた)。メスは約1日、オスは約0.8日あける。1回の交尾で、交尾なしにもう1〜2回産む。
- 不具合の修正: 交尾の演出でオスが先に終わると交尾が成立せず、同じペアが何度も交尾をくり返していた。
- 趣味の遺伝子: 多くのカメは、波乗り・観察・昼寝(nap、新規)・ただよう(drift、新規)のどれか1つがとても強い。波乗り好きは普通の波でもよく乗り、昼寝好きは昼間もよく眠り(Napper)、ただよい好きはひれを動かさず流される(Drifter)。観察好きはタコを好んで、長いあいだ見つめる。
- のんびりに: 怒りっぽい・おっちょこちょい・メスを追いかけ回す遺伝子は出にくく、元気な個体のダッシュも少なく。病気になる確率を半分に。
- 友情: ハートではなく、あわを出してあいさつし、友達と並んで同じ向きに泳ぐ(swimming side by side)。パートナーには花。
- 岩場とサンゴを大きく(部品を大きく、間隔も広く)。眠るカメは岩やサンゴのすき間にもぐりこみ、岩・サンゴの下に隠れて見える。
- 1匹あたりの海藻の計算から卵を外した(卵が多いと子ガメがほとんど外洋へ出てしまっていた)。卵の栄養のコストを下げ、交尾したメスが産卵前に飢えないように。

## Ver 7.3 の変更(何もせず眺めていても生態系が保たれる)
- 基本の考え方: プレイヤーは何もせず、のんきに暮らすカメを眺めて癒される。手を出さなくても海藻もカメも続くように調整。
- 海藻: 株を丸ごと食べるのをやめ、1ドットずつ(ひとくち=絵の1段)ゆっくりかじる。株の根元は残るので、すぐまた育つ。
- 食事はたまに: おなかの減り方を約4割に。ひとくちはゆっくり(2秒)。食事している時間の割合は、旧版とほぼ同じか少し多い程度(シミュレーションで約6%)。
- 卵を抱えたメスは上陸の前にしっかり食べる(産めずに卵を抱えたままになっていた)。
- カメが増えすぎない: 16匹を超えると恋をせず、混みすぎると何匹かが他の海域へ旅立つ(「The sea is getting crowded...」)。
- カメはいつも一番手前に表示(岩やサンゴに隠れない)。
- 岩場をさらに大きく(岩の絵1.25倍、広がり約1.5倍)。寝床は、ほかのカメの寝床や海藻から離れた場所を選ぶ。眠っているカメは押されない。

## 保存(Google ドライブ)
閉じたとき(と5分ごと)に `colony.json` を保存。次回起動時に閉じていた時間ぶん(カメの時間で最大30日)進める。
保存先はパソコン版 Google ドライブの同期フォルダ(`G:\マイドライブ\UmigamePet\` など)。見つからなければ `ホーム\UmigamePet\`(タイトルに「(saved locally)」)。環境変数 `UMIGAME_SAVE_DIR` で指定可。旧版の保存データも読める。
