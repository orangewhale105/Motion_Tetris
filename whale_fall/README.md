# Whale Fall(ホエールフォール)

Sea Turtle Colony と同じコンセプトの深海版。海を横から見た断面(矢状面)で、鯨骨に集まる深海の生き物の暮らしを見る。
`whale_fall.py` 1ファイル、Python 標準ライブラリ(tkinter)だけで動く。起動: ダブルクリック、または `python whale_fall.py`。表示は英語。

## 画面
上から 海面(空の色はパソコンの時計)→ 有光層(昼は光の筋)→ 中深層 → 漸深層 → 深海底(約4000m、右に深さの目盛り)。
マリンスノーが降り、海底にはクジラの死骸(鯨骨)が横たわる。カーソルは潜水艇のライトで、近くの生き物が明るく見える。

## 主役: ジュウモンジダコ(ダンボ・オクトパス)の群体
- パステル(ピンク・ピーチ・ライラック・クリーム・アクア・ミント)、まれに深い赤や紫。模様 7 種類(無地・そばかす・しま・発光点・ツートン・まだら・ハート)。耳(ひれ)の大きさ、発光の色も遺伝。
- 食性: ヨコエビ(甲殻類)を捕るのが得意な「hunter」と、骨のゴカイを食べるのが得意な「grazer」。
- 1日: 昼から夕方によく食べ、夜は海底や鯨骨の上で休む。メスは鯨骨や岩に卵を産みつけ、ふ化まで食べずに守る(力尽きることもある)。
- 1日で 1〜3 世代。友達・パートナー・悲しみ・さみしさ、合体・分裂は海亀版と同じ。

## 鯨骨生物群集の遷移(実時間)
| 段階 | 期間 | 様子 |
|---|---|---|
| 落下 | 1分 | クジラが海面から沈んでくる |
| 移動性腐肉食者期 | 〜18時間 | 肉が多くヨコエビが大発生。ヌタウナギ・オンデンザメが来る |
| 富栄養期 | 〜42時間 | 骨にホネクイハナムシ(赤い花のようなゴカイ)が咲く |
| 化学合成期 | 〜90時間 | バクテリアマットと二枚貝 |
| 鯨骨礁期 | その後 | 骨だけ。餌が少ない。12〜48時間後に新しいクジラが落ちてくる |

餌の量が段階で変わるので、タコは肉の多い時期に増え、骨だけになると減り、次のクジラで回復する(右上のグラフ)。

## 1日の変化(パソコンの時計)
- 夜: ハダカイワシの群れが上へ移動(日周鉛直移動)し、マリンスノーが増える。タコは休む。
- 朝: ハダカイワシが深みへ戻る。昼は有光層に光の筋。チョウチンアンコウは夜に現れやすい。

## 訪問者(まれ)
コウモリダコ(友好的。タコが集まって遊ぶ)、マッコウクジラ(イカを追って潜ってくる)、ダイオウグソクムシ(海底を歩く)、ヌタウナギ(肉のある時期)、オンデンザメ(海底近くのタコを狙う)、チョウチンアンコウ(光る疑似餌で好奇心の強いタコを誘う。逃げられることも)。

## 操作
| 操作 | 反応 |
|---|---|
| タコをクリック | ステータスがついて回る(深さ・食性・見た目・性格・関係など)。もう一度で消える |
| ダブルクリック | びっくりして腕を反らせた「傘」の姿勢になり、光る |
| タコの上でカーソルを動かす | なでる |
| 水をクリック | マリンスノーのかたまり(ヨコエビが湧く) |
| Shift+クリック | 魚の死骸を落とす(海底でヨコエビが集まる) |
| 重ねる | 卵・鯨骨・訪問者・ハダカイワシ・ヨコエビ・深さの説明 |
| 右クリック / L / R | 最前面 / 系統 / 関係の線 |

## 保存
閉じたとき(と5分ごと)に Google ドライブの同期フォルダの `WhaleFall/colony.json`(見つからなければ `ホーム\WhaleFall\`)。環境変数 `WHALEFALL_SAVE_DIR` で指定可。次回起動時に経過時間ぶん(最大7日)進める。
